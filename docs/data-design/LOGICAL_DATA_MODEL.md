# Logical Data Model — LMS

## 1. الهدف

تحديد البنية المنطقية للبيانات التي يحتاجها نظام إدارة المكتبة، دون ربط التحليل بمحرك قاعدة بيانات محدد. التنفيذ المرجعي يستخدم SQLite، لكن هذا النموذج يبقى صالحًا لأي RDBMS.

## 2. الكيانات

### Role
يمثل الدور الأمني للمستخدم داخل النظام: Admin أو Librarian أو Member.

### UserAccount
يمثل بيانات تسجيل الدخول وحالة الحساب وربطه بالدور.

### Member
يمثل العضو المستفيد من المكتبة. يمكن ربط العضو بحساب Member واحد للوصول إلى ملفه واستعاراته.

### Category
يمثل تصنيف الكتب.

### Book
يمثل بيانات الكتاب وعدد النسخ الكلي والمتاح.

### Loan
يمثل حدث استعارة كتاب بواسطة عضو، ويحتوي على تاريخ الاستعارة والاستحقاق والإرجاع الفعلي.

## 3. العلاقات

| العلاقة | الكاردينالية | الوصف |
|---|---|---|
| Role → UserAccount | 1:N | الدور الواحد يمكن أن يخص عدة حسابات |
| UserAccount → Member | 1:0..1 | حساب Member قد يرتبط بعضو واحد |
| Category → Book | 1:N | التصنيف يحتوي عدة كتب |
| Member → Loan | 1:N | العضو يمكن أن يملك عدة عمليات استعارة عبر الزمن |
| Book → Loan | 1:N | الكتاب يمكن أن يظهر في عدة عمليات استعارة عبر الزمن |

## 4. قواعد التكامل

1. كل UserAccount يجب أن يرتبط بدور موجود.
2. كل Book يجب أن يرتبط بتصنيف موجود.
3. كل Loan يجب أن يرتبط بكتاب وعضو موجودين.
4. `available_copies` لا تقل عن صفر ولا تتجاوز `total_copies`.
5. عند إنشاء Loan مفتوح تنخفض `available_copies` بمقدار 1.
6. عند إرجاع Loan مفتوح تزيد `available_copies` بمقدار 1.
7. الاستعارة لا تنفذ إذا كان العضو Inactive أو لا توجد نسخة متاحة.
8. حذف Book ممنوع عند وجود Loan مفتوح عليه.
9. `due_date` مطلوبة لكل Loan.
10. Loan متأخر إذا كان مفتوحًا و`due_date < CurrentDate`.
11. Member لا يستطيع الوصول إلى Member record غير المرتبط بحسابه.
12. حذف Category غير داخل النطاق الحالي.

## 5. حالات البيانات

### Member.status
- Active
- Inactive

### Loan.status
- Open
- Returned

### UserAccount.active
- 1 = Active
- 0 = Inactive

## 6. ملاحظة النسخ

لا يتم إنشاء كيان مستقل لكل نسخة مادية من الكتاب في النسخة الأكاديمية الحالية. يتم تمثيل المخزون بواسطة:

- `total_copies`
- `available_copies`

وهذا القرار متوافق مع تبسيط نطاق المشروع.
