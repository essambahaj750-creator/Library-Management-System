# Phase 1 — Software Requirements Specification (SRS)

This directory contains the approved requirements baseline for the Library Management System (LMS).

## Approved Scope

- One public library
- Physical books only
- Actors: Admin, Librarian, Member
- Borrowing and return transactions are recorded by Librarian/Admin
- Member can search, view permitted personal information, and review personal loans
- Reservations, financial fines, SMS/email notifications, e-books, and multiple branches are excluded

## Requirement Identifiers

- Problems: P-01 — P-06
- Objectives: OBJ-01 — OBJ-08
- Functions: FN-01 — FN-30
- Functional Requirements: FR-01 — FR-34
- Non-Functional Requirements: NFR-01 — NFR-16

The approved Arabic Word SRS document is the formal academic baseline for Phase 1.
