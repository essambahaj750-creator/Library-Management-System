# Activity Diagrams

## 1. نشاط تسجيل الدخول

```mermaid
flowchart TD
    S([Start]) --> A[إدخال اسم المستخدم وكلمة المرور]
    A --> B[التحقق من الحقول]
    B --> C{البيانات مكتملة؟}
    C -- لا --> E[عرض رسالة تحقق]
    E --> A
    C -- نعم --> D[التحقق من بيانات الاعتماد وحالة الحساب]
    D --> F{صحيحة والحساب فعال؟}
    F -- لا --> G[تسجيل محاولة فاشلة وعرض رسالة مناسبة]
    G --> H{بلغت المحاولات حد القفل؟}
    H -- نعم --> I[قفل مؤقت للحساب/المحاولات]
    H -- لا --> A
    I --> Z([End])
    F -- نعم --> J[إنشاء جلسة وتحميل صلاحيات الدور]
    J --> K[فتح الواجهة المسموح بها]
    K --> Z
```

## 2. نشاط استعارة كتاب

```mermaid
flowchart TD
    S([Start]) --> A[اختيار عضو]
    A --> B{العضو مسجل وفعال؟}
    B -- لا --> X[رفض العملية مع سبب واضح]
    B -- نعم --> C[اختيار كتاب]
    C --> D{توجد نسخة متاحة؟}
    D -- لا --> X
    D -- نعم --> E[تحديد موعد الإرجاع]
    E --> F{الموعد صالح؟}
    F -- لا --> X
    F -- نعم --> G[إنشاء سجل استعارة مفتوح]
    G --> H[خفض عدد النسخ المتاحة]
    H --> I{تمت العملية كاملة؟}
    I -- لا --> J[التراجع عن التحديثات]
    J --> X
    I -- نعم --> K[تأكيد نجاح الاستعارة]
    K --> Z([End])
    X --> Z
```

## 3. نشاط إرجاع كتاب

```mermaid
flowchart TD
    S([Start]) --> A[تحديد الاستعارة]
    A --> B{الاستعارة مفتوحة؟}
    B -- لا --> X[رفض العملية]
    B -- نعم --> C[تسجيل تاريخ الإرجاع الفعلي]
    C --> D[إغلاق سجل الاستعارة]
    D --> E[زيادة عدد النسخ المتاحة]
    E --> F{تمت العملية كاملة؟}
    F -- لا --> G[التراجع عن التحديثات]
    G --> X
    F -- نعم --> H[تأكيد نجاح الإرجاع]
    H --> Z([End])
    X --> Z
```

## 4. نشاط البحث عن كتاب

```mermaid
flowchart TD
    S([Start]) --> A[إدخال معيار البحث]
    A --> B[اختيار العنوان أو المؤلف أو التصنيف]
    B --> C[إرسال طلب البحث]
    C --> D[مطابقة الكتب]
    D --> E{توجد نتائج؟}
    E -- لا --> F[عرض لا توجد نتائج]
    E -- نعم --> G[ترتيب وعرض النتائج]
    G --> H[إظهار حالة التوفر لكل كتاب]
    H --> Z([End])
    F --> Z
```

## قواعد التحليل

- الاستعارة والإرجاع لا ينفذهما Member.
- نجاح الاستعارة أو الإرجاع يتطلب اكتمال تحديث سجل Loan وتوفر الكتاب كوحدة منطقية واحدة.
- البحث متاح حسب صلاحية المستخدم ويعرض حالة التوفر.
