# Data Flow Diagrams (DFD)

## 1. Context Diagram / Level 0

يعرض النظام كعملية واحدة ويتعامل مع الجهات الخارجية الثلاث.

```mermaid
flowchart LR
    A[Administrator]
    L[Librarian]
    M[Member]
    LMS((0. Library Management System))

    A -->|بيانات الدخول، إدارة الحسابات، أوامر الإدارة والتشغيل| LMS
    LMS -->|نتائج الدخول، بيانات النظام، تقارير الحالة| A

    L -->|بيانات الكتب والأعضاء، طلبات الاستعارة والإرجاع، البحث| LMS
    LMS -->|نتائج العمليات، التوفر، الاستعارات والمتأخرات| L

    M -->|بيانات الدخول، البحث، طلب عرض البيانات الشخصية| LMS
    LMS -->|نتائج البحث، التوفر، الملف الشخصي، الاستعارات الشخصية| M
```

## 2. DFD Level 1

يتم تفكيك النظام إلى خمس عمليات منطقية رئيسية وأربعة مخازن بيانات منطقية.

```mermaid
flowchart LR
    A[Administrator]
    L[Librarian]
    M[Member]

    P1((1.0 الوصول والصلاحيات))
    P2((2.0 الكتب والتصنيفات))
    P3((3.0 الأعضاء))
    P4((4.0 الاستعارة والإرجاع))
    P5((5.0 البحث والمتابعة))

    D1[(D1 المستخدمون والأدوار)]
    D2[(D2 الكتب والتصنيفات)]
    D3[(D3 الأعضاء)]
    D4[(D4 الاستعارات)]

    A -->|بيانات دخول وإدارة حسابات| P1
    L -->|بيانات دخول| P1
    M -->|بيانات دخول| P1
    P1 <--> D1
    P1 -->|حالة الدخول والصلاحيات| A
    P1 -->|حالة الدخول والصلاحيات| L
    P1 -->|حالة الدخول والصلاحيات| M

    A -->|إضافة/تعديل/حذف/عرض| P2
    L -->|إضافة/تعديل/حذف/عرض| P2
    P2 <--> D2

    A -->|تسجيل/تعديل/عرض عضو| P3
    L -->|تسجيل/تعديل/عرض عضو| P3
    M -->|عرض البيانات الشخصية| P3
    P3 <--> D3

    A -->|تسجيل استعارة/إرجاع| P4
    L -->|تسجيل استعارة/إرجاع| P4
    P4 <--> D2
    P4 <--> D3
    P4 <--> D4

    A -->|بحث ومتابعة| P5
    L -->|بحث ومتابعة| P5
    M -->|بحث وعرض الاستعارات الشخصية| P5
    P5 --> D2
    D2 --> P5
    P5 --> D4
    D4 --> P5
    P5 --> D3
    D3 --> P5

    P5 -->|نتائج البحث والتوفر والمتابعة| A
    P5 -->|نتائج البحث والتوفر والمتابعة| L
    P5 -->|نتائج البحث والتوفر والاستعارات الشخصية| M
```

## 3. تعريف العمليات

| العملية | الوصف | المتطلبات الأساسية |
|---|---|---|
| 1.0 الوصول والصلاحيات | الدخول والخروج والحسابات والأدوار ومنع الوصول غير المصرح | FR-01..FR-07 |
| 2.0 الكتب والتصنيفات | إضافة وتعديل وعرض وحذف الكتب وإدارة التصنيفات | FR-08..FR-14 |
| 3.0 الأعضاء | تسجيل وتعديل وعرض العضو والملف الشخصي والسجل | FR-15..FR-19 |
| 4.0 الاستعارة والإرجاع | تنفيذ عمليات الاستعارة والإرجاع وتحديث التوفر | FR-20..FR-24 |
| 5.0 البحث والمتابعة | البحث والتوفر والاستعارات الحالية والمتأخرة | FR-25..FR-34 |

## 4. مخازن البيانات المنطقية

- **D1 المستخدمون والأدوار:** بيانات حسابات الدخول والأدوار والصلاحيات.
- **D2 الكتب والتصنيفات:** بيانات الكتب والتصنيفات وإجمالي النسخ والمتاح.
- **D3 الأعضاء:** بيانات أعضاء المكتبة وحالتهم.
- **D4 الاستعارات:** بيانات الاستعارة وموعد الإرجاع والإرجاع الفعلي والحالة.
