# Contributing Workflow

This is an individual academic project, but changes follow a professional Git workflow.

## Before starting work

1. Select the approved User Story in Trello.
2. Confirm its GitHub Issue and requirement IDs.
3. Move the Trello card to **To Do** if it is ready.
4. Create a feature/fix branch from `develop`.

## While working

- Keep changes limited to the selected story.
- Use commits that reference the GitHub Issue.
- Keep the Trello checklist current.
- Move the card to **In Progress** when active work starts.

## Before merging

- Run relevant tests.
- Check the story Acceptance Criteria.
- Open a Pull Request to `develop`.
- Use the repository Pull Request template.
- Move the Trello card through **Testing** and **Review**.

## Completion

A story is complete only after:
- all checklist tasks are complete,
- acceptance criteria pass,
- the Pull Request is merged,
- the Trello card is in **Done**,
- and the GitHub Issue is closed as completed.
